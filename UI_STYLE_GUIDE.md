# Luna UI style guide

Luna Lumia follows the shared Luna Visia and Luna Vita visual language: `#111111`
background, translucent white surfaces and controls, `#f5f5f5` primary text,
`#a3a3a3` muted text, subtle white borders, compact tabs, rounded panels, and
responsive typography. Place the future icon at `ui/assets/lunalumia_logo.png`;
the UI intentionally displays a neutral placeholder until that file exists.
